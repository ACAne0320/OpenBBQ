---
title: 网站部署
description: 使用 Cloudflare Workers Builds 构建和部署 Fumapress 文档站。
---

文档站位于 `website/`，使用 Fumapress 静态模式。Cloudflare 通过 Workers Static Assets 提供生成的 `dist/public`，普通页面请求不执行 Worker。

## 本地验证

```bash
cd website
pnpm install --frozen-lockfile
pnpm types:check
pnpm build
pnpm exec wrangler deploy --dry-run
```

## Cloudflare Git 构建设置

| 设置 | 值 |
| --- | --- |
| 根目录 | `/website` |
| 构建命令 | `pnpm build` |
| 部署命令 | `npx wrangler deploy` |
| 生产分支 | `main` |

非生产分支预览可以使用 `npx wrangler versions upload`。

## Canonical URL

第一次部署得到 `workers.dev` 地址后，添加构建变量：

```text
PUBLIC_SITE_URL=https://<worker>.<account-subdomain>.workers.dev
```

修改后重新构建，使 canonical 链接、社交元数据和生成资产使用正式 origin。以后绑定自定义域名时再替换一次。
