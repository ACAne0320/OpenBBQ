---
title: Website Deployment
description: Build and deploy this Fumapress documentation site with Cloudflare Workers Builds.
---

The documentation site lives under `website/` and uses Fumapress static mode. Cloudflare serves the generated `dist/public` directory through Workers Static Assets without executing a Worker for normal page requests.

## Local validation

```bash
cd website
pnpm install --frozen-lockfile
pnpm types:check
pnpm build
pnpm exec wrangler deploy --dry-run
```

## Cloudflare Git build settings

| Setting | Value |
| --- | --- |
| Root directory | `/website` |
| Build command | `pnpm build` |
| Deploy command | `npx wrangler deploy` |
| Production branch | `main` |

For non-production branch previews, Cloudflare can use `npx wrangler versions upload`.

## Canonical URL

Add a build variable after the first deployment provides a `workers.dev` URL:

```text
PUBLIC_SITE_URL=https://<worker>.<account-subdomain>.workers.dev
```

Rebuild after changing this value so canonical links, social metadata, and generated assets use the production origin. Replace it again when a custom domain is attached.
