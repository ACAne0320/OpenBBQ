---
title: 快速开始
description: 用一句 Agent 提示词生成可编辑的双语字幕底稿和烧录后的视频。
---

这是在线 URL 与本地文件都推荐使用的默认路径。OpenBBQ 负责工作流状态和确定性校验，
Agent 负责语义翻译。

## 1. 检查安装

```bash
openbbq --version
openbbq doctor
openbbq models list
```

尚未缓存正式字幕模型时，先下载：

```bash
openbbq models pull large-v3-turbo
```

确保随包 Skill 为最新版：

```bash
openbbq skill install --agent all --force
```

## 2. 发送一句提示词

在线视频：

> 帮我把这个视频制作成中英双语字幕视频：https://www.youtube.com/watch?v=...

本地文件：

> 帮我把 `/path/to/video.mp4` 制作成中英双语字幕视频。

提示词中不需要解释下载、ASR、分批翻译、glossary 维护、字幕导出或烧录步骤；这些规则
由 Agent Skill 提供。

## 3. 让 Agent 完成任务

正常流程如下：

```text
fetch（仅 URL）-> 抽取音频 -> 转录 -> 校验/分段
               -> 每批不超过 20 条 cue 的翻译
               -> 导出 ASS -> 烧录一次 -> 交付检查 -> done
```

OpenBBQ 每次只返回一个权威的下一步。机械 action 会提供精确 argv 和执行策略。GPU
转录、带登录态的 fetch 与最终烧录可能需要在受限 sandbox 外运行；Agent 不应在宿主机
GPU 可用时擅自改用 CPU。

翻译批次会携带目标语言规则、标题与作者、相邻上下文和命中的 glossary 术语。翻译时
发现明确 ASR 错误，Agent 可以提交 cue-scoped source fix；可复用的修正会成为
glossary candidate，并在成功交付后安全发布。

## 4. 获取产物

完成后的 `done` 响应返回：

- `out/zh.ass`：可编辑的双语 ASS 字幕；
- `out/zh-burned.mp4`：烧录后的视频；
- 默认自动路径的 `quality: "draft"`；
- 默认自动路径的 `human_reviewed: false`；
- 非阻塞的质量提示或 glossary 发布告警。

默认流程只导出和烧录一次，不运行视觉 QA，也不会自动改用 `fansub-compact`。

<Callout title="质量预期">
  自动结果定位为可用的 70–80 分底稿。它应保持结构和 cue 对齐，但不代表每条字幕都
  经过专业人工确认。
</Callout>

## 继续专业精修

可以在同一个 workspace 中打开可选的浏览器编辑器：

```bash
openbbq review --workspace /path/to/workspace --to zh
```

也可以把 `out/zh.ass` 导入 Aegisub 或剪辑软件。人工修改具有最高权威，不要让自动
Agent 流程覆盖已经完成的人工工作。

登录与本地文件细节见[本地文件与在线视频](/zh/docs/guides/sources)；Agent 实现细节见
[Agent 与 JSON](/zh/docs/guides/agents)。
