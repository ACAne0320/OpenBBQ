## 前置要求

- Python 3.12 或更新版本。
- 使用 [uv](https://docs.astral.sh/uv/) 安装 `openbbq` 命令。
- 使用 FFmpeg 抽取音频和处理视频；烧录硬字幕还需要 libass 提供的 `ass`、`subtitles` filter。
- 一个 ASR 后端。OpenBBQ 目前通过 `pywhispercpp` 支持 whisper.cpp。
- 一个显式下载的 ASR 模型。
- 在线平台要求登录或人机验证时，需要本机桌面浏览器。

<Callout type="warn" title="平台支持">
  OpenBBQ 仍处于 pre-alpha 阶段，当前工作流主要在 macOS 上开发；Windows 和 Linux 支持仍在路线图中。
</Callout>

## 安装 CLI 与 Agent Skill

安装发布包和默认 whisper.cpp 后端：

```bash
uv tool install 'openbbq[whispercpp]'
openbbq skill install --agent all
```

Skill 会指导受支持的 Agent 遵循唯一权威的 `agent next/apply/finish` 工作流。只需
安装一个目标时，可使用 `--agent codex`、`--agent claude`，或默认共享的 `agents`
目标。

专业用户需要本地浏览器审核界面时，再加入对应 extra：

```bash
uv tool install --force 'openbbq[whispercpp,review]'
```

如果安装后找不到 `openbbq`，按 uv 输出的提示配置 PATH，然后打开新的 shell。

## 安装 FFmpeg

在 macOS 上，普通 Homebrew 包可以完成转录和大部分媒体处理：

```bash
brew install ffmpeg
```

烧录硬字幕需要包含 libass 的构建。`openbbq doctor` 会检查两个必要 filter，在 Homebrew 环境中也能发现 `ffmpeg-full`：

```bash
brew install ffmpeg-full
```

## 检查环境

`doctor` 是只读命令，可以安全地重复执行：

```bash
openbbq doctor
```

它会检查 Python、FFmpeg、字幕 filter、yt-dlp、ASR 后端、模型缓存和随包 Agent Skill。缺少必需项时，按输出中的 `fix` 处理。

机器可读输出：

```bash
openbbq --json doctor
```

## 下载模型

模型不会随安装包下载。先查看模型目录和缓存状态：

```bash
openbbq models list
```

快速预览可用 `base`（约 148 MB）；正式字幕建议从 `large-v3-turbo`（约 1.6 GB）开始：

```bash
openbbq models pull base
openbbq models pull large-v3-turbo
```

下载支持断点续传，默认保存在 `~/.openbbq/models/whisper.cpp/`。设置 `OPENBBQ_HOME` 可以改变 OpenBBQ 数据目录。

## 验证安装

```bash
openbbq doctor
openbbq --version
openbbq --help
```

需要烧录硬字幕时，确认 `ffmpeg subtitle filters` 同时报告 `ass` 和 `subtitles`。

## 升级或重装

```bash
uv tool upgrade openbbq
openbbq skill install --agent all --force
openbbq doctor
```

修改 extra 或修复 CLI 安装：

```bash
uv tool install --force 'openbbq[whispercpp,review]'
```

## 从仓库安装

只有开发时才使用仓库安装：

```bash
git clone https://github.com/ACAne0320/OpenBBQ.git
cd OpenBBQ
uv sync --extra whispercpp --extra review --dev
uv run openbbq --help
uv run pytest
```
