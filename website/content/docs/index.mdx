OpenBBQ is an open-source tool that turns foreign-language video into finished subtitles. You can drive it from the terminal yourself or let an AI agent run the commands for you. It downloads the video, writes down what it hears, translates line by line, checks the result, and burns the subtitles in.

In fansub circles, an untranslated video is "raw meat" and the finished release is "cooked meat". OpenBBQ handles the work between them.

<Callout title="Current status">
  OpenBBQ is pre-alpha software, currently developed on macOS with [Python](https://www.python.org/) 3.12, [FFmpeg](https://www.ffmpeg.org/), [yt-dlp](https://github.com/yt-dlp/yt-dlp), and a [whisper.cpp](https://github.com/ggml-org/whisper.cpp) recognizer. Review the output before publishing it.
</Callout>

## How OpenBBQ works

One video, one workspace folder. You move through the grill one step at a time, and every step saves its result as a plain file you can open and inspect:

```text
download → write down what it hears → cut into lines
→ translate → review → export subtitles → burn into video
```

Nothing hides in a black box. Stop anywhere, look at the files, fix something, and continue. OpenBBQ picks up where you left off. After each step it checks the work before moving on. If something looks off, it stops and waits for your call. Read more in [Workspaces and stages](/en/docs/concepts/workspaces) and [Quality gates](/en/docs/concepts/quality-gates).
