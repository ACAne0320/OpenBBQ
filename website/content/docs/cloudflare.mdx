---
title: Cloudflare deployment
description: Deploy the static Fumapress build with Cloudflare Workers Assets.
---

This validation site uses Fumapress static mode. Cloudflare serves the generated files from `dist/public` without invoking a Worker at request time.

## Build

```bash
pnpm build
```

## Preview on the Cloudflare runtime

```bash
pnpm preview:cloudflare
```

## Deploy

```bash
pnpm deploy
```

Set `PUBLIC_SITE_URL` to the production origin during the build so canonical URLs and generated social metadata use the correct domain.
