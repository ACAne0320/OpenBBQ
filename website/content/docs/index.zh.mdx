## OpenBBQ 是什么？

OpenBBQ 是一套本地优先的命令行工作流，用于转录、翻译、审校和发布双语视频字幕。

## 工作流程

1. 创建或检查工作区。
2. 转录源视频或音频。
3. 翻译并审校字幕片段。
4. 导出字幕，或将字幕烧录进最终视频。
