OpenBBQ 是一套开源工具，可以把外语视频变成做好的字幕。你可以自己在终端里操作，也可以让 AI Agent 替你运行命令：下载视频、把听到的话逐句记下来、逐行翻译、检查结果，最后把字幕烧进画面。

字幕组把未翻译的视频叫“生肉”，把译制完成的版本叫“熟肉”。OpenBBQ 负责中间的整套工作。

<Callout title="当前状态">
  OpenBBQ 仍处于 pre-alpha 阶段，目前主要在 macOS 上开发，使用 [Python](https://www.python.org/) 3.12、[FFmpeg](https://www.ffmpeg.org/)、[yt-dlp](https://github.com/yt-dlp/yt-dlp) 和 [whisper.cpp](https://github.com/ggml-org/whisper.cpp) 识别器。发布前请检查输出。
</Callout>

## OpenBBQ 的工作方式

一个视频对应一个工作区文件夹。你沿着流水线一步一步走，每一步都会把结果存成可以直接打开查看的普通文件：

```text
下载 → 把听到的话记下来 → 切成一行行字幕
→ 翻译 → 校对 → 导出字幕 → 烧录进画面
```

没有黑盒。你可以随时停下来，打开文件检查或修改，然后继续；OpenBBQ 会从中断的地方接着跑。每完成一步，它都会先检查再继续。发现问题时，它会停下来等你决定。详见[工作区与阶段](/zh/docs/concepts/workspaces)和[质量关卡](/zh/docs/concepts/quality-gates)。
